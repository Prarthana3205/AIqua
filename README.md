## Project Description

AIqua is a user-friendly web platform designed to engage citizens in the conservation of Bangalore's lakes. By leveraging geospatial data and algae metrics, AIqua classifies lakes into environmental threat levels, enabling users to understand the health status of each lake. The project involved extensive data collection and cleaning using Excel, where lake details, mineral presence, and other relevant parameters were systematically catalogued. The platform empowers citizens with actionable information and opportunities to participate in preservation efforts, fostering community-driven environmental stewardship. Through an intuitive interface, users can explore lake conditions and contribute to protecting vital urban water bodies.

## Tech Stack

- Frontend: React.js, JavaScript, CSS, HTML  
- Backend: Python (for data processing and analytics)  
- Data Management: Microsoft Excel (data collection, cleaning, and organization)  
- Data Visualization: Geospatial mapping libraries and custom algae measurement tools
